Entry & Onboarding
Welcome page
  • Continue as guest
  • Create account
  • Login
Guest mode
  • Choose up to 5 universities
  • Browse selected uni rooms + public space only
  • Fully read-only — posts & comments visible
  • All actions gated → prompts signup
Registration (multi-step)
  • Step 1 — full name, birthday, email, role (student/prof), major(s)
  • Step 2 — username, password, confirm password + OTP email verification (60s resend)
  • Step 3 — "Fin" page: go to dashboard / login / home + confetti 🎉
  • University & major from admin-approved DB dropdowns
Login & password reset
  • Login via username or email + password
  • Request reset → link sent to email
  • Reset password page
  • JWT session expiry checking in App.jsx
Dashboard — Tab System
Feed tab
  • Joined rooms filter
  • Search bar → Search page (users tab + posts tab)
  • Write a post → Post modal (room filter, title, description, attachment: link+label / image / PDF)
  • Feed filters: all / most recent / most popular
  • Refresh button
  • 3-type voting: Useful / Useless / Specialized
  • Optimistic UI on votes
Chat tab
  • AI assistant — main space
Profile tab
  • Header: email, rating, major, role tag
  • 6 stat cards: posts, comments, useful / useless / specialized votes, rooms joined
  • Drill-down history on each stat card
  • Saved posts sidebar
  • Connections page (following / followers tabs)
  • Edit profile: email, username, pfp, change password
  • Logout & delete account
Rooms tab
  • My rooms: public rooms (top) + private rooms (bottom)
  • Create private room / join private room
  • Private rooms: open chat → polling-based real-time chat
  • Browse rooms: major-filtered subject rooms, search + filter
  • Room request modal (if room not found)
Guide tab
  • Platform helper / onboarding guide
Admin Panel (permission-gated tabs)
Announcements
  • Post platform-wide announcements
Users tab
  • User list management
Professors tab
  • Handle professor status requests
  • Accept (after reviewing proof) or refuse
  • Refused → demoted to student + reoriented to valid major on next login
Reports
  • Handle reports on posts and comments
Resources
  • Consult user-published resources
Hidden content
  • Posts hidden by threshold or by admins
  • Leave hidden or restore
Custom input
  • Approve/reject custom major & university submissions
  • Approved → creates room; rejected → user picks valid input on next login
Room requests tab
  • Subject room requests from users
  • Accept or reject
Room moderation
  • Delete specific rooms
  • Suspend users from specific rooms
SuperAdmin Panel
Stats tab
  • Total users, posts, comments, rooms
  • Suspended users, pending professors, reported content
Admin management tab
  • Admin applications (rating ≥ 3.5)
  • Admin list with search & filter
  • SuperAdmin badge visual distinction
  • Edit/Remove hidden for superadmin entries
  • adminFilter dropdown
Logs tab
  • Action history per admin
  • Superadmin override on select actions

Architecture
Tech stack
  • Frontend: React 19 + Vite
  • Backend: Node.js / Express
  • DB: PostgreSQL on Supabase (pooler port 6543)
  • Raw SQL via node-postgres + toCamel.js utility
  • Auth: JWT with session expiry
  • Email: Nodemailer (OTP + password reset)
  • Chat: polling-based (private rooms)
Database
  • 27 relational tables
  • DB views for post/comment vote counts
  • otp_verifications table
  • Hierarchical rooms: faculty → department → subject
  • 3-type voting system
  • Audit log tables
  • Room-level suspension system
